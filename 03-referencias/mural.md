# Mural de referências

> Data: 2026-10-25 · Tipo: dados · Status: vigente

**Resumo:** o lugar para salvar links de Reels, vídeos, imagens, perfis e sites que chamaram sua atenção, com o motivo. É daqui que sai o pontapé inicial de uma marca ou de uma peça. Referência só de uma marca vai para o mural dela (`04-marcas/<marca>/referencias/mural.md`).

## Como preencher

Uma linha por link, na seção certa. Só o link já basta, mas o motivo ajuda muito.

- **Link:** o endereço completo.
- **O que chamou atenção:** em poucas palavras ("a transição de papel", "as cores", "o gancho", "a música").
- **Estilo:** o nome da ficha em `estilos/` (pixel-art, neobrutalismo...), se souber. Em branco, a IA identifica.
- **Status:** deixe `novo`. A IA atualiza: `novo` → `na fila` → `baixado` → `analisado` (com o link da análise).

Para baixar os vídeos e imagens marcados como `novo`: `uv run scripts/referencias.py mural --baixar`. Perfis e sites não são baixados: a IA abre e analisa direto.
